# Analysis of information obtained from different sources about MFML assignment.

## Context
An assignment was given to students of a certain course - Mathematical foundations for Machine Learning (MFML). The assignment contains two questions with three subparts in each. There are some instructions on the assignment document, however several details were not clear. Over the time, additional information has comeup — on official course website and by one particular Professor teaching the course.
The goal of this analysis is to go through all the different pieces of information, released at different time, on different channels and create a single, comprehensive and details clarification about each question (and each subpart) on the assingment.

## Details of the documents in the root directory
- Assignment_1_MFML.pdf — original assignment document with the problems to solve.
- Announcement by faculty.txt — Two messages posted by course faculty on the course website
- WhatsApp Chat with BITS MFML With Prof. Saurabh - 28 May.txt — Full text history of a whatsapp channel where one of the professors teaching the course posted clarifications and other information about the assignment (and many other things).
- /Study material shared by Prof. Saurabh
    - Assignment_1_Approach_and_Hints.pdf - detailed document with clarifications about each question on the assignment
    - Particular_and_Homogeneous_Solutions.pdf - Not directly related to the submission, but contains topics and concepts related to the questions on the assignment
    - three_decompositions.pdf — not directly related to the submission, but contains topics and concepts related to the questions on the assignment

## Details on the "WhatsApp Chat with BITS MFML With Prof. Saurabh - 28 May.txt" file
- The professors name is Saurabh.
- In students' messages he is referred as @Sarurabh in the chat transcript on several occasions.
- His responses are prefixed by "Saruabh:" in the chat transcript.

## Goals
- Create a new document - Final_MFML_Assignment_Clarifications.md
- Analyze all the document in the root directory, refer to information on this file.
- Generate a comprehensive report about clarificaions about each question and subpart on the assignment
    - Order them question wise
    - Give detailed instructions about the question
    - Include what is allowed and what is not.
    - Give examples for clarity.
    - Include any other information which would be relevant or important for solving the problem.
- At the top of the document mention that the document is AI generated and mention,in brief, what all information was used to genreate its content.
